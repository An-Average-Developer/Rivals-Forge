# ⚒️ Rivals Forge — Mod Manager for Marvel Rivals

**Rivals Forge** is a fast, lightweight mod manager for *Marvel Rivals*: install, organise, enable and disable your mods by hero, and get new ones from Nexus Mods without leaving the app.

---

## 🚀 Features

- **Mods by hero** — Every mod is grouped under its hero (found automatically in the ZIP), with a strip on top to show one hero's mods.
- **Nexus Store** — Browse, search and install *Marvel Rivals* mods from Nexus Mods (Premium downloads straight away; free accounts through the site's *Mod Manager Download* button).
- **Steam and Epic Games** — Every installation is detected, and your mods can be moved between them.
- **UTOC Signature Bypass Patch** — See at a glance whether it's installed, and get help installing it.
- **Play** — Launch the game from the header.
- **Themes** — Switch with the sun / moon button.
- **Automatic updates** — Rivals Forge checks this repository at startup and updates itself; the full changelog is inside the app.
- **Languages** — English, Spanish, French and Italian.

---

## 🧭 How to Use

1. **Download** `RivalsForge.exe` from the [latest release](https://github.com/An-Average-Developer/Rivals-Forge/releases/latest) and run it.
2. **The game is found automatically** (Steam or Epic). If it isn't, pick the `MarvelGame` folder.
3. **Add mods** with **＋ Add Mod** (ZIP files) or install them from the **Nexus Store**.
4. **Enable the ones you want** and press **Play**.

---

## 🔄 Updates

The app reads `version.txt` and `changelog.txt` from this repository. The automatic update downloads `RivalsForgev<x-y-z>.zip` from the latest release (e.g. `RivalsForgev1-0-0.zip` for 1.0.0); the manual update downloads [`RivalsForge.exe`](https://github.com/An-Average-Developer/Rivals-Forge/releases/latest/download/RivalsForge.exe) from the latest release.

To publish a new version: update both files and attach **both** `RivalsForgev<x-y-z>.zip` (with `RivalsForge.exe` inside) and `RivalsForge.exe` to a new release.
